## Categories

Categories sort records into kinds. **Admin > Categories** has a list for each:

- **Expense** and **Income** - what money is spent on and comes in for, for your books and reports
- **Referral** - how clients found you
- **Ticket** - what tickets are about: Network, Email, Onboarding
- **Network Interface**, **Asset Status**, **Software Type** and **Rack Type**
- **Contact Note Type** and **Asset Note Type**

![Categories](adm-categories.webp "Categories: a list for each kind, with what uses each one")

Each category shows as it looks on records, with its description and what uses it - click to see those records. Add one with the **New** button for the list you're on.

Each category's menu has:

- **Edit** - its name, colour, icon and description
- **Merge into** - fold it into another category of the same kind, moving everything over. Good for tidying "Hardware" and "Hardware Purchases" into one.
- **Archive** - it stays on its records, but isn't offered for new ones
- **Delete** - only while nothing uses it

Where the order of a list matters, such as asset statuses, drag the categories into the order you want.

## Tags

Tags are your own labels on records - "Managed", "Key Account", "Cyber Insurance", "Break Fix" on clients; "Licensed user" on contacts; "Loaner" on assets. Every list can be filtered by them.

A tag shows as a soft badge: its icon in the tag's colour, its name in the page's own text colour, on a faint wash of the colour with an edge of it. So a page full of tags stays easy to read, in light mode and dark - even a pale yellow or a near-black tag.

![Tags](adm-tags.webp "Tags: the tags for each kind of record, and how many records have each")

**Admin > Tags** has the tags for each kind of record: clients, locations, contacts, credentials, assets, vendors, domains, licenses, services, networks, documents and tickets. Each shows how it looks and how many records have it - click to see them.

Click **New** to add a tag with a name, a colour, an icon and a description of when to use it. Like categories, a tag can be edited, merged into another, archived (it stays on its records but isn't offered) or deleted.

> [!TIP]
> Tags can drive other things too. A recurring invoice can bill per user for contacts with a tag, and a document or license template can be required of every client with a tag - "every client tagged Managed should have a Network Overview".
